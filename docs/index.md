# Guia de Java

![Logo de Java](img/java.svg){ width="120" align=right }

Benvinguda a esta **guia pràctica de Java**, feta com a part del Projecte Intermodular.
Ací trobaràs els conceptes bàsics per a començar a programar en un dels llenguatges més utilitzats del món.

!!! info "Per a qui és esta guia?"
    Per a qualsevol persona que vulga **començar des de zero** amb Java, sense necessitat de coneixements previs avançats.

## Continguts

1. **Introducció**: què és Java i com instal·lar-lo.
2. **Fonaments**: sintaxi bàsica i programació orientada a objectes.
3. **Recursos**: documentació i enllaços per a continuar aprenent.

## Per què aprendre Java?

- :material-earth: **Multiplataforma**: *write once, run anywhere*.
- :material-briefcase: **Molt demandat** en el mercat laboral.
- :material-android: Base del desenvolupament **Android** i d'aplicacions empresarials.
- :material-account-group: Comunitat enorme i molta documentació.

!!! tip "Consell"
    Practica cada exemple en el teu ordinador. **Programar s'aprén programant.**

!!! success "Objectiu"
    Al final de la guia seràs capaç d'escriure, compilar i executar programes senzills orientats a objectes.
